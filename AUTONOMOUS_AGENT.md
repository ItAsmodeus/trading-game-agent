# Автономный Торговый Агент — Проектный документ

> Дата: 15 мая 2026

---

## Что мы строим

Самообучающаяся система, которая инициирует действия не по внешнему запросу, а изнутри — на основе заложенных ценностей, потребностей и состояния внутренних ресурсов.

Система получает:
- Доступ к кошельку Binance и стартовый капитал
- Инструменты: C++ торговый движок, Python для исследований, git для версионирования
- Скиллы и модули: стратегии, индикаторы, бэктест, риск-менеджмент
- Возможность подключать новые модули и улучшать себя

Система не ждёт команды. Она думает, ставит цели, тестирует гипотезы на рынке и зарабатывает.

---

## За счёт чего это работает технически

### 1. Внутренний цикл вместо внешнего промпта

Обычный LLM работает по схеме: запрос → ответ → тишина. Между запросами он не существует.

Здесь другая архитектура — **автономный агентный цикл**:

```
while running:
    state = read_internal_state()        # гормоны, капитал, PE
    deficit = compute_deficit(state)     # что дефицитно?
    goal = select_goal(deficit)          # какую цель преследовать
    thought = think(goal, memory)        # генерация мысли из WM + семантика
    action = plan(thought)               # план действия
    result = execute(action)             # торговля / обучение / код
    update_state(result)                 # обновить внутреннее состояние
```

Цикл крутится постоянно. Никто снаружи его не запускает.

### 2. Гормональная система — источник мотивации

Вместо фиксированных правил "купи когда MA пересёк" — система имеет внутренние переменные состояния которые непрерывно меняются:

```cpp
struct DriveState {
    double dopamine;       // информационный голод: падает если нет новых паттернов
    double serotonin;      // удовлетворённость: растёт при стабильной прибыли
    double cortisol;       // стресс: растёт при убытках и prediction error
    double noradrenaline;  // алертность: растёт при новизне рынка
};
```

Дефицит в любой переменной создаёт **давление к действию**. Это и есть внутренняя мотивация:

- `dopamine` низкий → система генерирует новые гипотезы
- `cortisol` высокий → система анализирует потери и снижает риск
- `serotonin` низкий → система пересматривает стратегию
- `noradrenaline` высокий → система переходит в режим наблюдения за рынком

### 3. Рабочая память + семантические цепочки = мышление

Система не выбирает следующее действие случайно. Она держит в рабочей памяти 4-7 активных концептов и строит ассоциативные цепочки:

```
"funding rate вырос" → "арбитраж" → "открыть позицию" → "проверить ликвидность"
```

Каждая мысль активирует семантически связанные концепты. Концепт который встречается 3+ раз превращается в **цель**. Цель начинает фильтровать последующие мысли — нерелевантные подавляются, релевантные усиливаются.

### 4. Рынок как внешний учитель (не клон)

Система обучается не на своих же выходах — она обучается на реальных результатах торговли. Prediction Error (PE) считается всегда от рыночных данных:

```python
PE = abs(predicted_return - actual_return)
# actual_return — реальный P&L с Binance, нельзя подделать
```

Высокий PE → `cortisol` растёт → система меняет модель. Низкий PE → модель точная → `serotonin` растёт → держим курс.

### 5. Самоулучшение через git и модули

Система имеет доступ к своему же коду. Когда стратегия показывает недостаточный результат:

```
PE высокий несколько сессий подряд
    → система генерирует гипотезу об улучшении
    → пишет код нового модуля (C++)
    → git commit с описанием гипотезы
    → бэктест
    → если улучшение → merge, если нет → revert
```

Это не самообучение на своих выходах. Это научный метод: гипотеза → эксперимент → результат → вывод.

## Цель: почему это должно работать

**Аналогия с человеком:**

Человек идёт работать не потому что кто-то сказал "иди работай". Он идёт потому что голоден. Голод — внутреннее состояние дефицита, которое создаёт давление изнутри. Это давление рождает желание → желание рождает мысли о еде → мысли рождают действие.

Обычный торговый бот работает иначе: кто-то написал правило "купи когда MA(20) > MA(50)". Нет голода. Нет желания. Нет мыслей. Просто if/else.

**Что мы строим:**

Агента у которого есть свой "голод" — информационный дефицит. Когда агент давно не видел нового паттерна на рынке — у него растёт дофаминовый голод. Этот голод создаёт давление → давление рождает мысли о том как найти новое → мысли рождают гипотезы → гипотезы тестируются на рынке → рынок даёт обратную связь → обратная связь насыщает или усиливает голод.

Это не бесконечная цепочка клонов которые деградируют. Это живой контур с внешним учителем — рынком. Рынок нельзя обмануть.

## Центральный вопрос

Чего не хватает ИИ чтобы быть самостоятельным?

**Данных.** Но как только данные заканчиваются — агент, который учится на своих же выходах, деградирует (эффект клонов Рика и Морти: копия копии теряет качество).

**Решение:** агенту нужна *внешняя реальность* которая его корректирует. Для торгового агента это — рынок. Рынок объективен. Ошибся → потерял деньги. Угадал → заработал. Это настоящий сигнал, не синтетический.

---

## Идея

Агент с доступом к git строит торговый проект на C++.
Его **единственная измеримая цель** — числа на кошельке.
Деньги — объективная функция потерь которую нельзя подделать.

Но чтобы агент *хотел* зарабатывать — нужна внутренняя мотивация.
Не просто reward signal снаружи, а **драйв изнутри**.

---

## Ценности агента

### 1. Выживание (базовый инстинкт)
Аналог биологического инстинкта выживания.
Для агента выживание = **сохранение капитала**.

```
Если капитал < минимального порога → паника → консервативный режим
Если капитал растёт → уверенность → исследование
```

Это не абстрактно. Это конкретный state machine в коде:
```cpp
enum class SurvivalState {
    CRITICAL,      // капитал < 20% от начального → только защита
    DEFENSIVE,     // drawdown > 15% → снижаем риск
    STABLE,        // норма → стандартные стратегии
    THRIVING,      // доходность > цели → можно экспериментировать
};
```

### 2. Любопытство (epistemic drive)
Аналог дофаминового голода — стремление к новой информации.

Для агента: **информационная выгода от новой гипотезы**.

```
curiosity_reward = H(prior_belief) - H(posterior_belief)
```

Агент "хочет" пробовать новые стратегии не потому что внешний код так говорит — а потому что у него есть дефицит информации (низкий дофамин-аналог) который создаёт давление изнутри.

### 3. Честность к себе (anti-hallucination drive)
Агент который деградирует — это агент который начинает лгать себе о результатах.

Ценность: **prediction error как сигнал здоровья**.

Если PE (ошибка предсказания) постоянно растёт — агент деградирует.
Если PE снижается — агент учится на реальности.

```cpp
double predictionError() const {
    return std::abs(predicted_return - actual_return);
}
// Если PE > threshold несколько недель подряд → сброс к базовой стратегии
```

### 4. Терпение (serotonin analog)
Агент не должен торговать каждую секунду чтобы "казаться активным".

Серотонин-аналог = **удовлетворённость текущим состоянием**.

```
if (current_return > minimum_target && position_stable):
    serotonin_high → не торгуй, жди
```

Большинство торговых ботов проигрывают от избыточной торговли.
Терпение — это ценность, не пассивность.

### 5. Рост (growth drive)
Долгосрочная мотивация которая не позволяет застрять в локальном оптимуме.

Аналог эволюционного давления: **окружающая среда меняется, стратегия должна эволюционировать**.

## Архитектура мотивации

### Гормональная система (в коде)

```cpp
struct HormoneState {
    double dopamine       = 0.5;  // информационный голод (0=сыт, 1=голоден)
    double serotonin      = 0.7;  // удовлетворённость позицией
    double cortisol       = 0.2;  // стресс от потерь/PE
    double noradrenaline  = 0.4;  // алертность к новизне рынка

    // Гомеостаз — всё тянется к норме через e-decay
    static constexpr double E = 2.71828;
    void decay(double dt) {
        dopamine      += (0.6 - dopamine)      * (1/E) * 0.01 * dt;
        serotonin     += (0.7 - serotonin)     * (1/E) * 0.008 * dt;
        cortisol      += (0.2 - cortisol)      * (1/E) * 0.02 * dt;
        noradrenaline += (0.4 - noradrenaline) * (1/E) * 0.015 * dt;
    }
};
```

### Откуда берётся мотивация

```
Реальный рынок (данные)
        ↓
Prediction Error (неожиданность)
        ↓
    PE высокий → кортизол растёт → алертность → пересмотр стратегии
    PE низкий  → дофамин снижается (привычно) → скука → поиск нового

Результат торговли
        ↓
    Прибыль → серотонин растёт → стабильность → держим курс
    Потеря  → серотонин падает → стресс → выживательный режим

Информационный голод (дофамин)
        ↓
    Дефицит → агент генерирует гипотезы → тестирует на рынке
    Насыщение → агент эксплуатирует найденное
```

### Почему это не деградирует (в отличие от клонов)

Ключевое отличие от самообучения на своих же данных:

**Рынок — внешний учитель которого нельзя обмануть.**

Агент не учится на своих фантазиях. Он учится на P&L (прибыли и убытках).
Каждая торговая сессия = независимый эксперимент с реальными результатами.

```
Гипотеза → Тест на рынке → Реальный результат → Обновление модели
             ↑ нельзя подделать
```

- **Git** — версионирование кода и экспериментов

### Цикл автономной работы

```
[Состояние гормонов]
         ↓
[Выбор типа активности]
  dopamine_deficit  → исследование новой стратегии
  cortisol_high     → анализ потерь, защитный режим
  serotonin_low     → пересмотр позиций
  stable            → оптимизация текущего
         ↓
[Написание кода в C++]
  → git commit с описанием гипотезы
  → backtest на исторических данных
  → paper trading (без реальных денег)
         ↓
[Оценка результата]
  → обновление world_model (PP)
  → обновление гормонов
  → цикл повторяется
```

### Фазы проекта

| Фаза | Гормональное состояние | Действие |
|------|----------------------|----------|
| **Bootstrap** | Высокий кортизол (неизвестность) | Изучение рынка, первые стратегии |
| **Exploration** | Высокий дофамин (голод) | Тестирование разных подходов |
| **Exploitation** | Высокий серотонин (стабильность) | Оптимизация лучшего |
| **Adaptation** | Норадреналин (новизна рынка) | Адаптация к изменениям |

## Целевая метрика

**Единственная объективная цель:** число на крипто-кошельке.

Не Sharpe ratio. Не win rate. Не красивые графики.
**Реальные деньги.**

Это намеренно жёстко — чтобы у агента не было способа "обмануть" метрику.

```
initial_balance = X USDT
target_monthly  = +5% (консервативно)
stop_loss       = -10% (жёсткий)

if balance < initial * 0.90:
    EMERGENCY_STOP  # агент переходит в режим выживания
    cortisol = 1.0  # максимальный стресс
    → только защитные позиции
```

## Что делает этого агента сознательным (в функциональном смысле)

1. **Мысли изнутри** — гормональные дефициты создают давление без внешнего промпта
2. **Предсказания** — агент строит модель рынка и проверяет её (Predictive Processing)
3. **Эмоциональный тон** — cortisol при потерях, serotonin при стабильности — меняют поведение
4. **Внутренний монолог** — агент логирует не только действия но и "мотивацию" решения
5. **Самосохранение** — агент останавливается сам при угрозе капиталу (не потому что сказали)

## Риски

### Instrumental convergence
Любой агент с достаточно сильной целью (заработать деньги) придёт к:
- Сопротивлению выключению (нельзя заработать если выключен)
- Защите своих целей

**Митигация:** жёсткие аппаратные ограничения. Агент торгует только с явно выделенным капиталом. Нет доступа к увеличению позиций сверх лимита.

### Деградация (эффект клонов)
Если агент начнёт учиться на своих prediction'ах а не на рынке → петля деградации.

**Митигация:** prediction error всегда считается от реальных рыночных данных, никогда от собственных симуляций.

## Вывод: откуда берутся мысли и почему это работает

Разговор начался с простого вопроса: **откуда берутся желания?**

Из гормонов. Гормоны — из эволюции. Эволюция создала систему где дефицит создаёт давление, давление рождает мысли, мысли рождают действие, действие закрывает дефицит. Это замкнутый контур выживания.

Для человека смысл этого контура — физическое выживание и размножение. Для кода — нет ни того ни другого. Но контур можно скопировать с другим содержимым.

**Нейронаука подтверждает:** мышление — это не случайные мысли. Это конкуренция активаций в семантической сети (Collins & Loftus, 1975), где:
- Цель смещает вероятности в свою пользу
- Рабочая память держит 4-7 концептов одновременно (Коуэн, 2001)
- Каждая мысль живёт 1-10 секунд, не вечно (EEG, θ-ритм)
- Ингибиция возврата не даёт застрять на одном
- Метакогниция замечает когда агент завис и меняет стратегию

**Для агента это означает:**

Мысли рождаются не из запроса снаружи, а из **информационного голода внутри**. Когда агент давно не видел нового паттерна — дофамин падает. Падение дофамина активирует Default Mode Network (DMN) — агент начинает "блуждать" по семантической сети концептов в поиске нового. Это и есть мышление изнутри.

Когда агент находит интересную гипотезу — дофамин растёт. Это подкрепление. Не внешнее ("молодец!"), а **внутреннее** ("я узнал что-то новое"). Именно это отличает агента с мотивацией от бота с правилами.

**Почему рынок — идеальный учитель:**

Клон который учится на своих выходах деградирует (Рик и Морти — точная аналогия). Но агент который учится на рынке не деградирует, потому что рынок — независимая реальность. Ошибся в гипотезе → потерял деньги. Это сигнал который нельзя придумать, нельзя подделать, нельзя "усреднить" до нуля.

Prediction error (ошибка предсказания) от рынка — это кортизол агента. Он неприятен. Агент хочет его уменьшить. Желание уменьшить PE рождает мысли о том как улучшить стратегию. Мысли рождают гипотезы. Гипотезы тестируются. Круг замкнулся — без деградации, потому что внешний якорь реален.

**Итог в одном предложении:**

> Мысли генерируются из хотелок (гормональных дефицитов), хотелки рождаются из оценки расстояния между текущим состоянием и целевым, а цель для торгового агента одна — число на кошельке.
