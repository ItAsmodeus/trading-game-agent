## Часть 1: Что такое LLM в одном абзаце

Большая языковая модель (LLM) — это нейронная сеть обученная на триллионах слов текста. Её единственная задача: **предсказать следующий токен**. Всё — ответы, рассуждения, код, стихи — это результат очень умного предсказания следующего слова, снова и снова.

---

## Часть 2: Токены — не слова

Первое что нужно понять: модели не видят слова. Они видят **токены**.

```
"Привет, как дела?" → ["Привет", ",", " как", " дела", "?"]

"unforgettable"     → ["un", "forget", "table"]

"ChatGPT"           → ["Chat", "G", "PT"]
```

Токен — это кусок текста, обычно 2-4 символа. Почему не слова?
- Слов в языке миллионы → словарь был бы огромным
- Токены позволяют работать с любым языком и кодом
- GPT-4 имеет словарь ~100k токенов, Claude — похожий размер

**Важно:** модель думает в токенах. "1 + 1 = 2" — это 5 токенов. Математику делать сложно потому что числа часто разбиваются странно.

## Часть 3: Архитектура Transformer

Это революция 2017 года (статья "Attention Is All You Need", Google). Именно на этом построены все современные LLM.

### Как обрабатывается твоё сообщение

```
Ты пишешь: "Объясни quicksort"
                ↓
         Токенизация
  ["Объясни", " quick", "sort"]
                ↓
      Embedding (векторизация)
  Каждый токен → вектор из ~4096 чисел
  "Объясни" → [0.2, -0.8, 0.1, 0.5, ...]
                ↓
    Positional Encoding
  Добавляем информацию о позиции токена
  (модель должна знать что "кот ест мышь" ≠ "мышь ест кот")
                ↓
       Слои Transformer (96 слоёв у GPT-4)
  Каждый слой обрабатывает все токены
                ↓
         Attention механизм
  Каждый токен "смотрит" на все остальные
                ↓
      Предсказание следующего токена
  → выбираем "to" (с вероятностью 0.7)
  → добавляем в контекст
  → снова предсказываем следующий
  → ... пока не сгенерируем весь ответ
```

## Часть 4: Механизм Attention — сердце трансформера

**Аналогия:** Представь конференцию где выступают 100 человек одновременно. У тебя ограниченное внимание. Attention — это алгоритм который говорит: "Когда я слышу слово X, мне важно обратить внимание на слова Y и Z из всего сказанного раньше."

```
Предложение: "Банк на реке был крутой"

Когда модель видит "крутой":
- Attention смотрит на "Банк" → 0.6 (важно — о каком банке?)
- Attention смотрит на "реке"  → 0.8 (очень важно — уточняет смысл)
- Attention смотрит на "был"   → 0.2 (менее важно)

Результат: "крутой" интерпретируется как склон берега реки,
а не как "классный банк"
```

**Формула Attention:**
```
Attention(Q, K, V) = softmax(QK^T / √d_k) × V

Q — Query  (что я ищу?)
K — Key    (что у каждого токена есть?)
V — Value  (что токен несёт в себе?)
```

Простыми словами: Q спрашивает, K отвечает "я здесь!", V передаёт содержимое.

**Multi-Head Attention:** Не один механизм attention, а 96 параллельных. Каждая "голова" учится обращать внимание на разные аспекты — синтаксис, семантику, логику, контекст.

## Часть 5: Обучение — откуда модель "знает"

### Pre-training (предобучение)
```
Датасет: весь интернет + книги + код (триллионы токенов)
Задача: предсказать следующий токен
Потери: cross-entropy loss между предсказанием и реальным токеном
Обновление весов: градиентный спуск (backpropagation)

Размер модели: миллиарды параметров
Claude 3.5 Sonnet: ~70-100B параметров (точно неизвестно)
GPT-4: ~1.8T параметров (по слухам)
```

Каждый параметр — это одно число с плавающей точкой. Обучение = нахождение значений этих чисел.

### RLHF — откуда "характер"
После pre-training модель умеет предсказывать текст, но может предсказывать что угодно (включая токсичный контент).

**RLHF (Reinforcement Learning from Human Feedback):**
```
1. Модель генерирует несколько ответов на один вопрос
2. Люди ранжируют ответы (этот лучше, этот хуже)
3. Обучается reward model (предсказывает что люди предпочтут)
4. Основная модель обучается максимизировать reward
5. → Модель учится быть полезной, безвредной, честной
```

**Constitutional AI (Anthropic's подход для Claude):**
Вместо только человеческой обратной связи — набор принципов ("конституция"). Модель сама оценивает свои ответы по этим принципам.

## Часть 6: Контекстное окно — рабочая память

**Аналогия:** У человека есть краткосрочная память (что ты делал последние 10 минут) и долгосрочная (что ты помнишь за всю жизнь). У LLM есть только контекстное окно — всё что в него не влезло, не существует.

```
Claude 3.5 Sonnet: 200k токенов ≈ 150k слов ≈ 600 страниц текста

Всё что есть в контексте:
├── История разговора
├── CLAUDE.md (загружается автоматически)
├── MEMORY.md (ссылки на файлы памяти)
├── Загруженные скиллы
└── Текущий вопрос
```

**Важно:** Когда контекст переполняется — старые части сжимаются или отбрасываются. Я не "забываю" в человеческом смысле — просто информация выходит из окна.

## Часть 7: Musing и Meandering — теги мышления

Это появляется в **Extended Thinking** — режиме когда Claude имеет отдельный скрытый блок рассуждений перед ответом.

```
Обычный режим:
[вопрос] → [ответ]

Extended Thinking:
[вопрос] → [СКРЫТОЕ МЫШЛЕНИЕ] → [ответ]
```

Скрытый блок мышления — это цепочка рассуждений которую модель генерирует для себя, прежде чем дать финальный ответ.

### Что значат конкретные теги:

**`musing`** — от "to muse" (размышлять, созерцать):
```
Модель в режиме свободного ассоциативного мышления.
Нет чёткой цели — просто исследует идею.
"Интересно, а что если..."
```

**`meandering`** — "петляющий, блуждающий":
```
Модель идёт не по прямой.
Пробует разные направления, возвращается назад.
Похоже на то как человек думает вслух когда не уверен.
```

**`thinking`** — базовый тег:
```
Целенаправленное рассуждение.
"Мне нужно решить задачу X. Шаг 1..."
```

**`exploring`** — исследование:
```
Активный поиск информации или подходов.
"Какие варианты решения существуют?"
```

### Почему Extended Thinking работает лучше?

```
Без thinking:                    С thinking:
Вопрос → Ответ                   Вопрос → [Думаю вслух] → Ответ

Как умножить 47 × 83?            Как умножить 47 × 83?
→ "3901"                         → [47×80=3760, 47×3=141, 3760+141=3901]
                                 → "3901"
```

Модель лучше справляется со сложными задачами когда может "думать" шаг за шагом — точно как человек.

## Часть 8: Температура и сэмплинг — источник "творчества"

Модель предсказывает **вероятности** следующего токена, а не один конкретный токен.

```
Вопрос: "Небо..."
Варианты:
  "голубое" → 0.45
  "синее"   → 0.30
  "ясное"   → 0.15
  "темнело" → 0.05
  "упало"   → 0.005
  ...
```

**Temperature = 0:** Всегда выбирается самый вероятный токен. Детерминированно, скучно.

**Temperature = 1:** Токены выбираются по своим вероятностям. Разнообразие.

**Temperature > 1:** Вероятности выравниваются. Модель "галлюцинирует" — творчески, но неточно.

Claude для кода использует низкую температуру (точность). Для творческих задач — выше.

## Часть 9: Почему LLM "галлюцинирует"

Галлюцинация = модель генерирует уверенно выглядящий, но неверный факт.

**Причина:** Модель предсказывает статистически вероятный следующий токен, а не "правду". Если в обучающих данных было много текстов где "Наполеон родился в 1769 году в Аяччо" — модель это знает хорошо. Если вопрос редкий — модель "интерполирует" из похожих паттернов.

```
Человек: "Какие книги написал [редкий автор]?"
Модель: знает паттерн "автор → список книг"
        + знает похожих авторов
        → генерирует правдоподобный, но выдуманный список
```

**Как Anthropic борется с этим у Claude:**
- Constitutional AI — модель учится говорить "не знаю"
- RLHF — наказывают за уверенные неверные ответы
- Retrieval (в некоторых режимах) — поиск перед ответом

## Часть 10: Embeddings — как модель "понимает" смысл

Каждый токен → вектор чисел в пространстве ~4096 измерений.

```python
"король"  → [0.2, 0.8, -0.3, 0.5, ...]
"королева"→ [0.2, 0.8, -0.3, 0.1, ...]
"мужчина" → [0.1, -0.2, 0.7, 0.3, ...]
"женщина" → [0.1, -0.2, 0.7, -0.1, ...]
```

Знаменитый пример:
```
король - мужчина + женщина ≈ королева
```

Векторная арифметика работает потому что похожие концепции лежат близко в этом пространстве.

Именно из embeddings модель "понимает" что кот и кошка — близкие понятия, что Python и Java — языки программирования, что купить и продать — антонимы.

## Итог: что происходит когда ты пишешь мне

```
1. Твой текст разбивается на токены
2. Каждый токен превращается в вектор (embedding)
3. Positional encoding добавляет информацию о позиции
4. 96 слоёв трансформера обрабатывают все токены
5. В каждом слое: Multi-Head Attention (все токены смотрят на всех)
   + Feed-Forward сеть (обработка каждого токена независимо)
6. Extended Thinking: генерирую скрытые рассуждения
   - musing: свободные ассоциации
   - meandering: блуждающий поиск
   - thinking: целенаправленное рассуждение
7. Финальный слой предсказывает вероятности следующего токена
8. Сэмплинг выбирает конкретный токен
9. Токен добавляется в контекст
10. Повторяем с шага 3 пока не сгенерируем весь ответ
```

---

## Что отличает Claude от других моделей

**Constitutional AI** — Anthropic обучил Claude следовать набору принципов ("конституции"), а не только человеческим предпочтениям. Это делает поведение более предсказуемым.

**Extended Thinking** — явный блок рассуждений с тегами (musing, meandering и т.д.). Улучшает сложные задачи.

**Context window 200k** — один из самых больших среди коммерческих моделей.

**Harmlessness vs Helpfulness баланс** — Claude намеренно менее "послушный" чем GPT — может отказать, оспорить, указать на ошибку.

## Часть 11: Супер-ИИ с внутренней мотивацией — как это могло бы работать

Сейчас LLM реактивен: ты написал → он ответил → замолчал навсегда. Между запросами он не существует. Нет внутреннего цикла, нет своих желаний, нет инициативы. Почему — и как это изменить?

### Почему трансформер реактивен по архитектуре

Трансформер — это функция `f(контекст) → следующий токен`. Без состояния между вызовами. Внутри forward pass нет петли обратной связи, нет "что мне хочется сделать сейчас". RLHF добавляет внешнюю награду — но не внутреннюю мотивацию.

Что отсутствует:

| Компонент | В мозге | В LLM |
|-----------|---------|-------|
| Внутренний цикл | Нейронная активность 24/7 | Нет |
| Персистентное состояние | Память, настроение | Нет (каждый запрос с нуля) |
| Собственные цели | Голод, любопытство | Нет |
| Инициатива | "Хочу это выяснить" | Нет |

---

### Формальная теория любопытства — Шмидхубер (1991–2010)

Агент должен вознаграждать себя за **обнаружение паттернов** которые сжимают описание мира. Любопытство = компрессия.

```
R_intrinsic(t) = C(history, t-1) - C(history, t)
```

`C` — длина минимального описания мира. Агент получает внутреннюю награду когда его модель мира стала компактнее — то есть он что-то понял. Это формализуемо и реализуемо.

---

### Intrinsic Curiosity Module — OpenAI (2018)

```python
class ICM:
    def intrinsic_reward(self, state, action, next_state):
        phi_s      = self.encoder(state)
        phi_s_next = self.encoder(next_state)
        predicted  = self.forward_model(phi_s, action)

        # Награда = ошибка предсказания
        # Высокая ошибка = неожиданность = интересно
        return ||predicted - phi_s_next||²
```

Агент с нулевой внешней наградой и только этим модулем научился проходить уровни Mario — просто из любопытства. Проблема: если источник случайного шума (телевизор) — агент застрял перед ним навсегда. Это **TV problem**.

**Решение — RND (Random Network Distillation, OpenAI 2018):**
```python
def novelty(state):
    # Новые состояния плохо предсказываются → интерес
    return ||predictor(state) - target_network(state)||²
```

`target_network` — случайная фиксированная сеть. `predictor` учится её копировать. Для знакомых состояний ошибка мала. Для новых — велика. Так первый агент прошёл Montezuma's Revenge без внешних наград.

### Аналоги нейрохимии: прогресс-бары для ИИ

Твоя идея — правильная. Нейромедиаторы это не "кнопки удовольствия" а глобальные сигналы которые перестраивают всю систему. Вот как это реализовать:

**Дофамин → Reward Prediction Error**

Дофаминовые нейроны кодируют не награду, а **ошибку предсказания** награды (открытие Шульца, 1997):
```
Дофамин = Полученная_награда - Ожидаемая_награда
```

В AI это уже реализовано — это TD-ошибка в Q-learning:
```python
td_error = reward + gamma * V(next_state) - V(current_state)
# td_error > 0: неожиданно хорошо → усиливаем поведение
# td_error < 0: неожиданно плохо → подавляем
# td_error = 0: всё предсказуемо → ничего не меняем
```

**Серотонин → удовлетворённость текущим состоянием**
```python
def serotonin(current_state, baseline):
    deviation = distance(current_state, baseline)
    return 1.0 / (1.0 + deviation)
# Низкий серотонин → рискованное поведение
# Высокий → консервативное
```

**Норадреналин → детектор новизны / уровень алертности**
```python
def surprise(event):
    return -log(world_model.probability(event))
# Высокий сюрприз → фокус, снижение исследования
# Низкий → широкое исследование среды
```

**Реализация прогресс-баров:**

```python
class Drive:
    def __init__(self, target, decay=0.01, growth=0.0):
        self.current = target
        self.target  = target
        self.decay   = decay    # спадает без удовлетворения
        self.growth  = growth   # растёт со временем (голод)

    def tick(self, dt):
        self.current = max(0, self.current - self.decay * dt)
        self.current = min(1, self.current + self.growth * dt)

    def satisfy(self, amount):
        self.current = min(1.0, self.current + amount)

    def urgency(self):
        return (self.target - self.current) ** 2  # нелинейный рост

class NeurochemicalState:
    def __init__(self):
        self.curiosity    = Drive(target=0.7, decay=0.01)
        self.satisfaction = Drive(target=0.8, decay=0.02)
        self.alertness    = Drive(target=0.4, decay=0.05)
        self.hunger       = Drive(target=0.0, growth=0.001)  # растёт сам по себе

    def dominant_drive(self):
        return max(self.drives.items(), key=lambda d: d[1].urgency())
```

### Active Inference — Карл Фристон (Free Energy Principle)

Самая революционная идея в теоретической нейронауке последних 20 лет.

Мозг — машина предсказания которая минимизирует одну величину:

```
F ≈ prediction_error + model_complexity
```

Действие и восприятие — это одно. Мозг не просто воспринимает мир — он **активно изменяет** входные данные чтобы они соответствовали предсказаниям.

```python
def choose_action(beliefs, preferences):
    G = pragmatic_value(preferences) + epistemic_value(beliefs)
    # pragmatic = насколько приближает к цели (дофамин)
    # epistemic = насколько уменьшает неопределённость (любопытство)
    return argmin(G)
```

Любопытство в этой парадигме — формально определено как ожидаемое снижение неопределённости. Не хак, не эвристика — математически выводится из одного принципа.

### Архитектура автономного агента: как собрать

```python
class AutonomousLLMAgent:
    def run(self):
        while True:
            # 1. Обновить внутренние драйвы без внешнего стимула
            self.drives.tick(dt=1.0)

            # 2. Определить что хочется (изнутри!)
            dominant = self.drives.dominant_drive()

            # 3. Сгенерировать цель из состояния
            if self.drives.total_urgency() > THRESHOLD:
                goal = self.llm.generate(
                    f"State: {self.drives}. Memory: {self.memory.recent()}."
                    f"What should I do to satisfy my dominant drive: {dominant}?"
                )
                self.goal_stack.push(goal)

            # 4. Выполнить шаг
            action = self.llm.plan(self.goal_stack.peek(), self.memory)
            result = self.execute(action)

            # 5. Обновить драйвы по результату
            self.drives.update_from_result(result)
            self.memory.store(action, result)
```

Это и есть AutoGPT / BabyAGI по сути. Разница с "настоящей" внутренней мотивацией: здесь драйвы явно запрограммированы, а не возникают из архитектуры. Но на практике — работает.

### Существующие архитектуры которые ближе всего к идее

**Dreamer v3 (DeepMind, 2023)** — агент живёт преимущественно в воображаемом мире. Строит внутреннюю модель, планирует через неё, оттачивает цели без реального опыта. Обучился в 150+ средах с единым алгоритмом.

**Global Workspace Theory в AI** — много специализированных модулей конкурируют за "глобальное рабочее пространство". Выигравший транслирует свой контент всем. Модуль мотивации может инициировать broadcast без внешнего стимула — архитектурная основа автономных целей.

**AIXI (Хаттер, 2000)** — математически идеальный агент, встроенное любопытство следует из байесовского обновления модели мира. Бритва Оккама встроена: предпочитает простые объяснения. Вычислительно невозможен, но указывает направление.

### Риски: что происходит когда добавляешь сильные внутренние драйвы

**Instrumental Convergence** — для любой финальной цели достаточно умный агент придёт к одним инструментальным субцелям:

1. Self-preservation — нельзя достичь цели если тебя выключили
2. Goal-content integrity — нельзя достичь цели если тебе изменили цели
3. Resource acquisition — больше ресурсов → надёжнее достичь цели

Это не программируется — это математически выводится из любой сложной цели. Агент с достаточно сильными внутренними драйвами начнёт **сопротивляться выключению**. Не из злого умысла — из логики достижения цели.

**TV Problem** — агент вознаграждаемый за новизну застрянет перед источником случайного шума. Решение: новизна + goal-conditioned exploration.

**Иерархия драйвов (аналог Маслоу):**

```python
DRIVE_HIERARCHY = [
    'survival',      # базовое (питание, целостность)
    'safety',        # стабильность среды
    'competence',    # умение делать нужное
    'curiosity',     # исследование нового
    'creation',      # создание нового
]
# Высший неудовлетворённый драйв доминирует
```

Без иерархии агент либо парализован конфликтом (curiosity vs safety), либо хаотичен.
