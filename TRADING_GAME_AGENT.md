### Моё мнение об идее

**Что сильно:**

Аналогия с игрой — не метафора, это буквально правильная постановка задачи. AlphaGo не знал правил игры заранее в смысле стратегий — ему дали только правила (что разрешено, что выигрыш). Рынок — идеальная среда для такого агента: чёткие правила, объективный результат, непрерывная обратная связь.

Конкуренция двух агентов — это GAN для трейдинга. Один агент учится на ошибках другого. Это ускоряет обучение.

**Что сложно:**

Рынок — нестационарная среда. Стратегия которая работает в 2024 может не работать в 2025. Агент который выучил паттерны одного режима не обобщается. Это главная причина почему 95% RL-ботов не доходят до прода.

**Почему всё равно стоит делать:**

Потому что сам процесс — лаборатория. Агент который ищет стратегии сам найдёт то что ты не догадаешься задать ему руками. Это разведка неизвестного пространства стратегий.

### Аналог настольной игры

```
Информация:  полная история цен + текущий стакан + новости

```

Это clean формулировка. Агент не знает как зарабатывать — он знает только правила.

### Правила игры (формально)

```python
class TradingGame:
    """
    Правила игры для RL-агента.
    Агент не знает стратегий — только правила.
    """

    # Константы игры
    STARTING_CAPITAL  = 10_000    # стартовый капитал USDT
    WIN_TARGET        = 1_000_000 # цель
    LOSS_THRESHOLD    = 0.20      # проигрыш при потере 80%
    MAX_EPISODES      = 365       # максимум дней

    # Комиссии (реальные условия Binance)
    MAKER_FEE = 0.001  # 0.1%
    TAKER_FEE = 0.001  # 0.1%
    SLIPPAGE  = 0.0005 # 0.05%

    def reward(self, prev_portfolio, curr_portfolio, action):
        """
        Функция вознаграждения — сердце игры.
        """
        pnl = (curr_portfolio - prev_portfolio) / prev_portfolio

        # Штраф за бездействие при дрейфе рынка
        inaction_penalty = -0.001 if action == 'HOLD' and abs(pnl) > 0.02 else 0

        # Штраф за чрезмерное плечо
        leverage_penalty = -0.01 * max(0, self.leverage - 3)

        # Штраф за просадку
        drawdown = (self.peak - curr_portfolio) / self.peak
        drawdown_penalty = -drawdown * 0.5 if drawdown > 0.10 else 0

        return pnl + inaction_penalty + leverage_penalty + drawdown_penalty

    def is_game_over(self, portfolio):
        if portfolio >= self.WIN_TARGET:
            return True, "WIN"
        if portfolio <= self.STARTING_CAPITAL * self.LOSS_THRESHOLD:
            return True, "LOSS"
        return False, None
```

## Архитектура: Два Агента

### Почему два агента лучше одного

Один агент учится на рынке. Но рынок огромный и медленно даёт обратную связь.

Два агента играют друг против друга — это **Self-Play**:
- Агент A пытается заработать
- Агент B пытается предсказать что сделает A и торговать против
- Оба учатся быстрее потому что противник адаптируется

Это то как AlphaGo стал лучше всех людей: играл сам с собой миллионы партий.

## Почему это может не сработать (честно)

### Проблема нестационарности

Рынок меняет режим: то тренд, то боковик, то кризис. Агент обученный на одном режиме не работает в другом. Люди решают это интуицией — агент не умеет.

**Митигация:** переобучение каждые 2 недели на свежих данных + детектор смены режима.

### Проблема execution

В симуляции нет slippage, нет частично исполненных ордеров, нет проблем с ликвидностью. В реале всё это убивает стратегию.

**Митигация:** реалистичный симулятор с bid/ask spread + slippage model.

### Проблема reward hacking

Агент найдёт способ максимизировать reward функцию способами которые ты не ожидал. Пример: открыть огромное плечо на 1 секунду — риск велик, но если повезёт reward будет максимальным.

**Митигация:** сложная reward функция с множеством штрафов + hard constraints.

### Goal-Conditioned Reward ($1M как цель) — самое мощное

Вместо "максимизируй returns прямо сейчас" — "мне нужно $1M через 12 месяцев":

```python
def reward_goal_conditioned(portfolio, target=1_000_000, time_left_days=365):
    progress = portfolio / target               # 0.0 → 1.0+
    time_fraction = time_left_days / 365        # 1.0 → 0.0
    urgency = progress - (1 - time_fraction)    # опережаем или отстаём?

    # Близко к цели — консервативный режим
    risk_multiplier = 3.0 if progress > 0.9 else 1.0

    return urgency - risk_multiplier * current_drawdown
```

Агент сам понимает: далеко от цели → умеренный риск. Близко → защищается.

## Почему наивный RL провалится — честно

**5 причин провала (из реальных экспериментов):**

**1. Regime Change.** Обучен на bull 2020–2021 → попадает на bear 2022 → всё что знал — неверно. Решение: переобучение каждые 2 недели + детектор смены режима.

**2. Overfitting.** Sharpe 3.0 в бэктесте = Sharpe 0.5 в live. Агент запоминает конкретные свечи. Решение: adversarial validation — тест на данных которые агент "не видел".

**3. Execution gap.** В симуляции купил по close. В реальности: slippage, частичные заполнения, rejected orders. Решение: симулятор с реальным bid/ask spread.

**4. Reward Hacking.** Агент найдёт способ получить reward без реального заработка. Пример: торгует 500 раз в день мелкими лотами. Решение: штраф на количество сделок.

**5. Non-stationarity.** Рынок адаптируется к твоим стратегиям. Решение: position limits + постоянное переобучение.

**Red flags — агент деградирует если:**
- Более 50 сделок в день → overtrading
- Win rate падает >10% за неделю → деградация
- Avg position change > 0.8 → нет уверенности

## Рекомендуемая стратегия (не всё или ничего)

**Не строй** чистый RL бот который заменяет всё — слишком рискованно.

**Строй гибрид:**

```
Уровень 1: Хардкод стратегии (Funding Arb, Stat Arb)
           → надёжный базовый доход

Уровень 2: RL агент управляет АЛЛОКАЦИЕЙ между стратегиями
           и РАЗМЕРОМ позиций

Уровень 3: Self-play в симуляторе → emergent patterns
           → лучшие вручную добавляешь в систему

Уровень 4: News sentiment как дополнительный signal
           Goal-conditioned reward ($1M) → агент сам регулирует риск
```

**Метрика успеха RL агента:**
- Out-of-sample Sharpe > 1.2 (не in-sample!)
- Max Drawdown < 20% включая 2022 bear market тест
- Работает в bull, sideways и bear
