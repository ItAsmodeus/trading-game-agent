## Принципы этого агента

```
1. Не ночевать в позиции — закрывать до конца дня
2. VWAP — торговать от отклонений от дневного VWAP
3. Скорость — реакция быстрее чем swing, медленнее чем scalper
4. Новостной нейтралитет — не торговать за час до FOMC/CPI
5. Объём первичен — без объёмного подтверждения нет входа
```

## Управление позицией

```
Стоп-лосс:    -1.5% (жёстче чем swing!)
Тейк-профит:  +3.0% (R:R = 1:2)
Макс держать: 24 часа (24 бара)
НЕ держать позицию через 22:00 МСК (закрытие амер. рынка)
Макс просадка: -10% → пауза (жёстче swing)
Ордеров/день: ≤ 100
```

---

## Ключевые отличия от Swing

```
Swing    → смотрит на тренд недели/месяца
Intraday → смотрит на тренд часа/дня
Swing    → новости важны (Fear&Greed)
Intraday → новости важны только крупные (FOMC, CPI, листинги)
Swing    → R:R 1:2 при 3%/6% стоп/тейк
Intraday → R:R 1:2 при 1.5%/3% стоп/тейк
```
