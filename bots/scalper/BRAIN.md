**Почему не торгует:**
```
1. Reward function заточена под дневные данные:
   - Движение 5м свечи = 0.05% → reward ≈ 0.0005
   - Штраф за просадку = 3.0 * dd² → перекрывает любую прибыль
   - Агент выучил: HOLD = минимальный убыток

2. 200k шагов = ~7 дней 5-минутных данных → слишком мало
   Swing получает 200k шагов × 700 дней = богатый опыт
   Scalper получает 200k шагов × 7 дней = нищий опыт

3. Нет правильных признаков:
   Текущая observation = дневные технические индикаторы
   Нужны: OBI, VWAP, тик-моментум, стакан
```

## Принципы скальпинга

```
1. Скорость важнее точности — войти и выйти за минуты
2. Стакан — единственный источник правды на 5м
3. Крупный игрок всегда оставляет след — iceberg = сигнал
4. VWAP — магнит цены на интрадей горизонте
5. Комиссия убивает — входить только при высокой уверенности
6. Никаких overnight позиций
```

## Что нужно сделать (технический долг)

### Приоритет 1: Отдельная Reward Function для скальпера

```python
def scalper_reward(pnl, cost, position_held_bars):
    """
    Для скальпера важно:
    - Штраф за длительное удержание (не ДЕРЖИ — ТОРГУЙ)
    - Меньший штраф за просадку (движения маленькие)
    - Штраф за overtrading компенсируется прибылью
    """
    ret = pnl / portfolio

    # Маленький штраф просадки (dd² вместо 3*dd²)
    dd_penalty = 0.3 * (dd ** 2) if dd > 0.03 else 0.0

    # Штраф за долгое удержание (скальпер должен быстро выходить)
    hold_penalty = -0.0001 * max(0, position_held_bars - 3)

    # Штраф за комиссии
    cost_penalty = cost / portfolio * 5.0

    return ret - dd_penalty - hold_penalty - cost_penalty
```
