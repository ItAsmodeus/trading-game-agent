## Принципы этого агента

```
1. Терпение — ждать качественных сигналов, не торговать ради торговли
2. Тренд — входить по среднесрочному тренду, не против него
3. Перепроданность — лучшие точки входа на откатах
4. Диверсификация сигналов — RSI + BB + MACD не коррелируют
5. Сезонность — учитывать исторические паттерны крипто
```

## Сигналы и пороги (актуальные)

| Сигнал | Лонг-порог | Шорт-порог | Вес |
|--------|-----------|-----------|-----|
| RSI | < 40 | > 60 | Высокий |
| MACD | > 0.001 | < -0.001 | Высокий |
| Bollinger | < -0.6 | > +0.6 | Высокий |
| Объём | > 1.3x | > 1.3x | Средний |
| Моментум 5д | < -5% + отскок | > 5% + разворот | Высокий |
| Тренд 20д | > +5% | < -5% | Средний |
| Тело свечи | > 1.5% | < -1.5% | Средний |
| Сезонность | Окт/Ноя/Янв/Апр | Авг/Сен | Слабый |
| Волат.сжатие | ATR<1.5% + нижн.BB | ATR<1.5% + верхн.BB | Средний |
| Funding Rate | FR < -0.05%/8ч | FR > +0.05%/8ч | Высокий |
| Fear & Greed | < 25 (Extreme Fear) | > 75 (Extreme Greed) | Средний |

**Правило:** минимум 2 сигнала одного направления → вход разрешён.

