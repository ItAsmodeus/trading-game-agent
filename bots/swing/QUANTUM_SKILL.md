# ⚛️ Скилл: Квантовый Скачок — Log-Normal Price Model

> Основан на математике Блэка-Шоулза и Геометрического Броуновского Движения.
> Число e — фундамент движения любой цены в природе.

---

## Суть: Цена растёт как природа — экспоненциально

Всё в природе растёт через e: популяции, бактерии, деньги на депозите.
Цена акции/крипты — не исключение.

```
P(t) = P(0) × e^(μt + σW(t))

P(0)  — цена сегодня
μ     — естественная скорость роста (drift, оцениваем из истории)
σ     — волатильность (стандартное отклонение лог-доходностей)
W(t)  — случайный шок рынка (непредсказуем)
e     — 2.71828... (основание натурального логарифма)
```

## Три сигнала для агента

### Сигнал 1: Z-Score — насколько цена далека от "нормы"

```python
log_returns = np.log(prices / prices.shift(1))
mu    = log_returns.rolling(60).mean()   # средняя доходность
sigma = log_returns.rolling(60).std()    # волатильность

# Ожидаемая цена через 1 день:
expected_price = current_price * np.exp(mu)

# Z-score: сколько "сигм" отклонение от ожидаемого
z_score = (current_price - expected_price) / (sigma * current_price)

# z_score < -2: цена слишком дёшево → покупай
# z_score > +2: цена слишком дорого → продавай
```

### Сигнал 2: Натуральный дрифт (μ) — тренд за 60 дней

```python
mu_60d = log_returns.rolling(60).mean()

# μ > 0: актив естественно растёт → поддерживает лонг
# μ < 0: актив естественно падает → поддерживает шорт
# μ ≈ 0: боковик → не торгуем
```

### Сигнал 3: Волатильность (σ) — риск момента

```python
sigma_20d = log_returns.rolling(20).std() * np.sqrt(252)

# σ < 0.40: низкая волатильность → нормальный размер позиции
# σ > 0.80: высокая волатильность → уменьшить позицию
# σ > 1.20: экстремальная → не торговать
```

## Как добавить в observation space агента

```python
# Добавить в environment.py:
log_ret = np.log(df["close"].iloc[i] / df["close"].iloc[i-1])
mu_60   = np.log(df["close"].iloc[i] / df["close"].iloc[max(0,i-60)]) / 60
sigma_20 = df["close"].pct_change().iloc[i-20:i].std()

# Z-score от ожидаемой цены
expected = df["close"].iloc[i-1] * np.exp(mu_60)
z_score  = (df["close"].iloc[i] - expected) / max(sigma_20 * df["close"].iloc[i], 1e-8)
z_score  = np.clip(z_score, -3, 3)  # нормализуем

# Итого 3 новых признака: mu_60, sigma_20, z_score
```

## Правила входа на основе Log-Normal

```
ПОКУПАТЬ когда:
  z_score < -1.5   (цена на 1.5σ ниже ожидаемой)
  И μ > 0          (естественный тренд вверх)
  И σ < 0.80       (волатильность в норме)

ПРОДАВАТЬ когда:
  z_score > +1.5   (цена на 1.5σ выше ожидаемой)
  ИЛИ μ < -0.001   (тренд сменился на нисходящий)

ШОРТИТЬ когда:
  z_score > +2.0   (сильно перекуплен)
  И μ < 0          (нисходящий тренд)
```

## Связь с Ваней Поповым (контанго)

```
Контанго на MOEX: Фьюч = Акция × e^(r × t)
  r = ставка ЦБ
  t = дни до экспирации

Funding Rate в крипте: та же математика
  FR > 0 → лонги переплачивают → "цена завышена"
  FR < 0 → шорты переплачивают → "цена занижена"

В обоих случаях e определяет справедливую цену.
```

---

## Почему это "квантовый скачок"

Обычные трейдеры смотрят на цену линейно.
Log-Normal модель смотрит в пространстве логарифмов —
там движения симметричны и предсказуемы.

Это не квантовая физика буквально, но:
- Используется та же математика что в квантовой механике (волновые функции)
- Переход от линейного к логарифмическому пространству = смена парадигмы
- Именно на этом основан весь опционный трейдинг (Блэк-Шоулз)
