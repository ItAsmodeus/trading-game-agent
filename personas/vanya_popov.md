## Стратегия которую он описал — Spot-Futures Арбитраж (контанго)

### Механика

```
Актив: Акции Сбербанка vs Фьючерс на Сбербанк (MOEX)

Справедливая цена фьючерса = Цена акции × (1 + ставка ЦБ × дней/365)
Это называется контанго — фьюч дороже акции на размер ставки ЦБ.

Аналог в крипто: Funding Rate Arbitrage (delta-neutral)
  Крипто-фьюч стоит дороже/дешевле спота → возникает "плата"
  Точно такая же математика.
```

### Когда входить

```
Условие: фьючерс девиировал от справедливой цены
  (кто-то кинул большой ордер → спред краткосрочно изменился)

Действие:
  Если фьюч стал слишком дорог → SHORT фьюч + LONG акция
  Если фьюч стал слишком дёшев → LONG фьюч + SHORT акция

Горизонт: секунды (иногда 3 секунды до закрытия)
```

### Plan Minimum vs Plan Maximum

```
Plan Minimum: ловить внутридневные колебания вокруг справедливой цены
  - Предсказуемо, стабильно, маленький edge
  - Нужна скорость: миллисекунды

Plan Maximum: парсить сайт ЦБ России в реальном времени
  - Если ЦБ изменил ставку → справедливая цена всех фьючей изменилась мгновенно
  - Кто первый пересчитает и нажмёт кнопку → "сверхдоходность"
  - Нужна инфраструктура co-location рядом с биржей
```

### Корпоративные события (backwardation)

```
Дивиденды → фьюч торгуется НИЖЕ акции (backwardation)
  Причина: фьюч экспирирует ПОСЛЕ дивидендного гэпа → уже без дивов
  Если экспирация в августе, дивиденды в июле → фьюч стоит меньше

Торговля: если дивиденд известен → можно посчитать справедливую разницу
  и ловить момент когда рынок её неправильно оценивает
```
