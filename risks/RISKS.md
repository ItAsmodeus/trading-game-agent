# ⚠️ Риски проекта Trading Game Agent

## Критические риски (могут убить проект)

### РИСК-1: Конкуренция с институционалами на их поле
**Откуда:** Никита Котковский
**Суть:** Если мы пытаемся торговать на тех же таймфреймах и теми же методами что Citadel/Jump — мы проигрываем всегда. Их инфраструктура стоит сотни миллионов. Co-location серверы в 10 метрах от биржи. Latency 0.1 мс против наших 50 мс.

**Как работать:**
```
✅ НЕ идти в HFT (таймфреймы < 1 минуты)
✅ НЕ идти в market making (нет капитала на инвентарь)
✅ ИДТИ в дневные/часовые стратегии — HFT там не конкурент
✅ ИДТИ в funding rate arbitrage — это их не интересует
✅ ИДТИ в кросс-биржевой арбитраж — интересно, но нужна скорость
```

**Индикатор:** Если стратегия требует исполнения быстрее 1 секунды → уходим.

---

### РИСК-2: Переоценка результатов бэктеста
**Откуда:** Никита + backtest-python скилл
**Суть:** Sharpe 2.16 в бэктесте ≠ Sharpe 2.16 в live. Реальность: OOS Sharpe = 40-60% от бэктеста. Sharpe 2.16 → ожидай 0.8-1.3 в live.

**Как работать:**
```
✅ Минимум 6 месяцев OOS тестирования прежде чем live
✅ Testnet 30 дней — обязательный шаг
✅ Никогда не ставить реальные деньги без testnet профита
✅ Стресс-тест на 2022 bear market (BTC -75%)
✅ Walk-forward validation — не один тест, а 10 разных периодов
```

**Индикатор:** Если OOS Sharpe < 0.8 → стратегия не готова к live.

---

### РИСК-3: Недостаток капитала для масштабирования
**Откуда:** Никита
**Суть:** Стратегия с Sharpe 1.5 на $1,000 даёт $150/год. Это не бизнес.

**Как работать:**
```
✅ Фокус на % доходности, не абсолютной прибыли
✅ Стратегия которая работает на $1k должна работать на $100k
✅ Привлечение партнёров/инвесторов ПОСЛЕ доказанных результатов
✅ Альтернатива: продать стратегию или алгоритм, а не торговать самому
```

**Текущая математика:**
```
$10,000 × Sharpe 1.1 ≈ +10% год ≈ $1,000
$100,000 × Sharpe 1.1 ≈ $10,000/год — уже интересно
$1,000,000 × Sharpe 1.1 ≈ $100,000/год — серьёзно
```

---

### РИСК-4: Нестационарность рынка
**Откуда:** Ева + RL-engineer скилл
**Суть:** Стратегия которая работала в 2023 может не работать в 2025. Рынок меняет режим. Обученный на бычьем рынке агент теряется на медвежьем.

**Как работать:**
```
✅ Rolling Training — переобучение каждые 2 месяца
✅ Детектор смены режима (bull/bear/sideways)
✅ Отдельные модели для разных режимов
✅ Постоянный мониторинг деградации Sharpe
```

**Красный флаг:** Sharpe упал >30% за 2 недели → модель устарела.

---

### РИСК-5: Reward Hacking
**Откуда:** pre-mortem скилл
**Суть:** Агент найдёт способ максимизировать reward не так как мы задумали. Пример: сидеть в кэше всегда → нет просадки → отличный Sharpe → 0 сделок.

**Как работать:**
```
✅ Проверять не только Sharpe но и количество сделок
✅ Штраф за слишком долгое бездействие
✅ Минимум 10 сделок за тестовый период
✅ Анализировать дневник — читать ПОЧЕМУ агент входил
```

**Текущий пример:** Scalper v1.0 — 0 сделок, Sharpe 0. Формально "не убыточен". Фактически — сломан.

## Средние риски (требуют внимания)

### РИСК-6: Бан на бирже
**Суть:** Binance блокирует подозрительную активность — wash trading, слишком много ордеров, паттерны HFT.

**Как работать:**
```
✅ Max 50 ордеров/день (swing), 100 (intraday), 500 (scalper)
✅ WebSocket для данных, не REST polling
✅ Случайные задержки между ордерами
✅ LIMIT ордера (maker), не MARKET (taker)
✅ Не торговать одинаковыми размерами (паттерн)
```

### РИСК-7: Технический сбой во время позиции
**Суть:** Интернет упал, сервер перезагрузился, API вернул ошибку — позиция открыта, управления нет.

**Как работать:**
```
✅ Автоматический стоп-лосс на бирже (exchange-side stop)
✅ Heartbeat мониторинг — бот пингует сам себя каждые 60 сек
✅ Telegram алерты при падении бота
✅ Kill switch — ручное закрытие всех позиций
```

### РИСК-8: Look-ahead bias в данных
**Суть:** Используем данные из будущего при расчёте индикаторов → Sharpe фиктивный.

**Как работать:**
```
✅ Только rolling window (не expanding)
✅ Нормализация только на train данных
✅ Все индикаторы вычислять через shift(1)
```
